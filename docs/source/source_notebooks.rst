.. _source-notebooks:

Notebooks
=========

Browse the runnable examples below, or use :doc:`tutorial` to find a guide and
notebooks for a specific analysis. Each workflow page lists the notebooks in
run order; the rendered notebooks include their saved results.

Run them with the **Python (spAlignDE-notebooks)** kernel from
:doc:`installation`. Each notebook sets its random seed before randomized
steps. See :doc:`tutorials/reproducibility` when comparing runs and
:doc:`tutorials/parameter_tuning` when adapting an example to your own data.
