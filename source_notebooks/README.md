# Source notebooks

These executable notebooks are published with saved outputs in the
[documentation](https://dsong-lab.github.io/spAlignDE/source_notebooks.html).
Follow [Installation](https://dsong-lab.github.io/spAlignDE/installation.html)
and select the **Python (spAlignDE-notebooks)** kernel.

Each workflow page lists its required inputs, preparation steps, notebook run
order and outputs:

| Workflow | Guide and notebook order |
|---|---|
| Single or joint ST clustering | [Clustering](https://dsong-lab.github.io/spAlignDE/source_notebooks/clustering.html) |
| Cross-sample ST alignment | [Mouse brain](https://dsong-lab.github.io/spAlignDE/source_notebooks/cross_sample_alignment_mouse_brain.html) · [Kidney](https://dsong-lab.github.io/spAlignDE/source_notebooks/cross_sample_alignment_mouse_kidney.html) · [Breast cancer](https://dsong-lab.github.io/spAlignDE/source_notebooks/cross_sample_alignment_breast_cancer.html) |
| ST to Allen CCF | [Atlas workflow](https://dsong-lab.github.io/spAlignDE/source_notebooks/cross_modality_atlas_alignment.html) |
| Spatial ATAC to ST | [ATAC and MERFISH S3R1 preparation, then alignment](https://dsong-lab.github.io/spAlignDE/source_notebooks/cross_modality_atac_alignment.html) |
| ST to H&E | [Xenium Rep1 clustering, H&E processing and alignment](https://dsong-lab.github.io/spAlignDE/source_notebooks/cross_modality_he_alignment.html) |
| Transformation variability | [Subsampling and mean displacement](https://dsong-lab.github.io/spAlignDE/source_notebooks/cross_sample_uncertainty_qualification.html) |
| Post-alignment inference | [Kidney and five-section aging brain](https://dsong-lab.github.io/spAlignDE/source_notebooks/post_alignment_inference.html) · [Your own aligned data](https://dsong-lab.github.io/spAlignDE/tutorials/own_aligned_data.html) |

For settings and comparisons across runs, see
[Reproducibility](https://dsong-lab.github.io/spAlignDE/tutorials/reproducibility.html).
Edit notebooks in this directory; the documentation build stages them
automatically, and generated copies are not tracked by Git.
